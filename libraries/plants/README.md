# Pflanzenquellen und Bildrechte

Die App nutzt den gebündelten Katalog unter `app/src/main/assets/plant-catalog.json`.
Dieser Ordner enthält die botanischen Quellen, Lizenzangaben und Einzelprüfungen
für die Pflege dieses Katalogs. Import: `python3 tools/import_plant_library.py`.
Bildvorbereitung: `python3 tools/prepare_plant_images.py --help`.
